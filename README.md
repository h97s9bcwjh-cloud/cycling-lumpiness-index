# Cycling Lumpiness Index — CLI v3.0

A client-side GPX calculator for the candidate Cycling Lumpiness Index (CLI v3.0).

## What it does
Upload a GPX file and the page:
- reconstructs the route elevation profile;
- calculates frozen CLI v3.0;
- displays a colour-coded 0–10 score and category;
- plots the ride elevation profile; and
- shows the CLI component breakdown.

The GPX is processed locally in the browser.

## Publish with GitHub Pages
1. Create a new GitHub repository (for example `cycling-lumpiness-index`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/(root)`, then save.
6. GitHub will provide the public Pages address after deployment.

For a project repository the usual address is:
`https://YOUR-USERNAME.github.io/cycling-lumpiness-index/`
